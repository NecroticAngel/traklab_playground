Control Characteristics

Precision

TCU - Electrical Characteristics

Power Grid
  • Power Source Dedicated PV module powered (12 – 55Vdc); In-line / String powered (200 – 1200Vdc / 200 – 1500Vdc)
  • Backup Power 24V Lithium-Ion (3.3Ah / 6.6Ah Options)
  • Battery Charger Intelligent constant current, constant voltage (CC/CV) charging
  • Drive Type Brushed DC Motor (24V, Max 10A)
